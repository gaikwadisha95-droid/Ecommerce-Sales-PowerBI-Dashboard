# E-Commerce Sales Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze e-commerce sales,
profit, orders, customers, and delivery performance.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel
- CSV

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Features
- Sales analysis
- Profit analysis
- Category analysis
- Customer analysis
- Delivery performance
- Interactive slicers and filters

## Key Insights
- Identified top-performing categories
- Analyzed sales and profit trends
- Compared delivery partner performance
- Identified late delivery patterns
